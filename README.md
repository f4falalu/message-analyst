# Chat Archive Hub

i have a download of entire whatsapp chat with attachments. I need to archive the requests for record purposes.  it's a year's worth of data (about 12949 message(s), 3936 photo(s) ~2.9GB). the output should be like a spreadsheet with parsed info: facility name, list of items and quantity, amount paid, date of request, date of payment, person's contact info - so you'll have to cross-reference the chat.txt and the attachments to make sense of it.

i want to be able to attach/upload the zip file and the system does the operation and processing.
